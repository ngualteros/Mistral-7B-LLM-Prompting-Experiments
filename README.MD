
# Mistral 7B — LLM Prompt Engineering Experiments

## Overview

This repository documents academic experiments involving the Mistral 7B large language model (LLM).

The project was developed as part of the Master's in Artificial Intelligence at Universidad Internacional de La Rioja (UNIR).

Its purpose is to explore practical aspects of prompt engineering and working with generative AI models through Python notebooks.

## Technologies

- Python
- Jupyter Notebook
- Mistral 7B
- Large Language Models (LLMs)
- Generative AI
- Prompt Engineering

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/mistral-7b-prompt-engineering.git
cd mistral-7b-prompt-engineering
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Open the notebook

```bash
jupyter notebook notebooks/01_mistral_7b_prompting.ipynb
```

Note: Running the notebook may require additional model dependencies, access permissions, or specific hardware. These requirements will be documented after validating the implementation.
